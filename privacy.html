Privacy notice

This notice applies to Home Assistant Nest, a personal integration operated by the owner of the GitHub account Ryan-Langleya> for their own household. It is not a public service.

Data accessed and purpose

With the account holder's consent, the integration accesses Google Nest device identifiers, names and room information; thermostat temperature, humidity, modes and settings; supported camera live streams; and motion and doorbell events. OAuth credentials and tokens enable authorised access. Data is used to display and manage the operator's own devices in Home Assistant and receive updates via Google Cloud Pub/Sub.

p>

Processing and storage

Google processes device data through its Nest services, Smart Device Management API and Cloud Pub/Sub. Home Assistant processes authorised data on the operator's privately managed system. Integration credentials and tokens are stored by Home Assistant. Device states, event history and logs may be retained according to the operator's Home Assistant configuration; Pub/Sub messages follow the configured subscription retention. This notice does not promise a fixed deletion period. Camera access does not itself mean that this informational website records or stores footage.

Disclosure and security

The operator does not sell Nest data or use it for advertising. This informational website contains no device data, credentials or camera feeds and has no analytics or collection forms added by the operator. GitHub Pages hosts the website and may process visitor connection information under GitHub's privacy statementa>. Google services process data under their applicable policies. Authorised administration and troubleshooting of the private installation may involve the operator's chosen tools and service providers; this notice does not assert that device data can never leave the private installation.

Revocation and deletion

The account holder can revoke the integration's access in Google Account third-party connections and remove the Nest integration and its application credentials from Home Assistant. Revocation stops future authorised access but does not automatically erase existing local history, backups or cloud messages. The operator can remove retained data, backups and Pub/Sub resources separately according to their configuration.

Contact and changes

The account holder is also the operator and controls this personal integration. The operator is identified by the GitHub profile linked above. Do not post credentials, device information or other private data in public repository issues. Updates to this notice will be published on this page.
